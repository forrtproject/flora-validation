Source records is every row ingested from the entry sheets and from the records this project has validated itself. That table is insert-only and each row keeps the date it first arrived, so this line is real history.

FLoRA dataset is what survives the exclusion list and duplicate resolution. The published dataset only changes when the pipeline regenerates it, so on a day with no run the figure is the one the last run produced. It begins on the first day the pipeline recorded it and is not extended backwards: applying today’s rules to an older set of rows would produce a number that was never true on that day.

About these numbers

FLoRA dataset
The published collection: what remains of the source records once duplicates are merged, the exclusion list is applied and incomplete entries are dropped.
Source records
Every record ingested, from the entry sheets and from records this project has validated itself. Each keeps the date it first arrived, so this line is exact history rather than an estimate.
Replications and reproductions
A replication repeats a study with new data. A reproduction re-analyses the original study’s data. Both counts are recorded with the dataset at every pipeline run, so each has its own history from the first measurement.
Days without a pipeline run
The dataset only changes when the pipeline regenerates it. On a day with no run, the figure from the last run is carried forward, and the table marks that day.
Before the first measurement
The dataset line begins on the first day the pipeline recorded it. It is not extended backwards: applying today’s rules to an older set of records would produce a number that was never true on that day.
Dates
Every date is a UTC calendar day, and each day shows the count at its end. Today’s figures are the latest available.

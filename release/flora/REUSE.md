# Reusing FLoRA

The dataset is licensed under Creative Commons Attribution 4.0 International
(CC BY 4.0): https://creativecommons.org/licenses/by/4.0/ . Attribute the dataset
creators using this version's CITATION.cff, cite the published version DOI and
state any filters, transformations and access date. Source publications retain
their own rights; this licence does not grant rights to their full texts.

A row links a report to an original study; rows are not independent effect sizes.
Outcomes reflect report authors' claims and coding guidance, not an independent
assessment of study quality. Read CODEBOOK.md and FAQ.md before pooling outcomes.
Missing values do not mean failure. FLoRA is a living resource whose coverage and
coding can change. Pin the version and retain permanent IDs for reproducibility.

Submit corrections through the FLoRA record editor in flora-validation (the
append-only correction log), then regenerate the published snapshot. Do not edit
release outputs to correct records. Retired IDs remain reserved in the registry.
